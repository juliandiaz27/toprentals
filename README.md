# TOP RENTALS

Sitio web — React + Vite + Tailwind. Tipografía **Inter**.

## Desarrollo

```bash
npm install
npm run dev
```

## Video del banner

1. Copiá el mp4 del diseño a `public/hero-banner.mp4`, o
2. Definí `VITE_HERO_VIDEO_URL` en `.env` (ver `.env.example`).

Sin video, el navegador muestra el fondo oscuro del hero (podés agregar `VITE_HERO_VIDEO_POSTER`).
